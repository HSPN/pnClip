# PNClip

AppKit과 Objective-C++로 만든 간단한 영역 캡처 앱입니다.

- 파란 테두리 안쪽은 투명하여 뒤 화면이 그대로 보입니다.
- 테두리를 드래그하면 창을 이동할 수 있습니다.
- 창이 활성화된 상태에서 `⌘S` 또는 메뉴 막대의 **캡처 → 캡처**를 선택하면 테두리 안쪽을 PNG로 저장합니다.
- `⌘R`을 누르면 현재 창의 내부를 24fps GIF로 녹화하며, 다시 누르거나 10초가 지나면 자동 저장합니다.
- **캡처 → 녹화 중 마우스 입력**을 켜고 녹화를 시작하면 중앙 영역의 클릭이 뒤쪽 앱으로 전달됩니다.
- **파일 → 저장 위치 변경…**에서 PNG와 GIF가 저장될 폴더를 선택할 수 있습니다. 기본값은 바탕화면입니다.
- 캡처와 녹화 결과는 자동으로 클립보드에도 복사됩니다. `⌘O`는 최근 결과를, `⌥⌘O`는 저장 폴더를 엽니다.
- 메뉴 막대의 PNClip 아이콘을 누른 뒤 화면에서 드래그하면 해당 영역 크기로 새 창이 만들어집니다. `Esc`로 취소할 수 있습니다.
- 저장 위치는 사용자의 바탕화면입니다.

## 실행

Xcode가 설치되어 있지 않아도 Command Line Tools가 있다면 다음으로 빌드할 수 있습니다.

```sh
make
open build/PNClip.app
```

`make`는 macOS가 화면 기록 권한을 동일한 앱에 유지할 수 있도록 앱 번들 전체를
로컬 키체인의 `PNClip Development` 인증서와 `com.example.PNClip` 식별자로 서명합니다.
처음 캡처할 때 화면 기록 권한을 허용한 후 앱을 다시 실행하세요.

Xcode에서는 `PNClip.xcodeproj`를 열고 Run을 누르면 됩니다.
