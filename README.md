# PNClip

AppKit과 Objective-C++로 만든 간단한 영역 캡처 앱입니다.

- 파란 테두리 안쪽은 투명하여 뒤 화면이 그대로 보입니다.
- 테두리를 드래그하면 창을 이동할 수 있습니다.
- 창이 활성화된 상태에서 `⌘S` 또는 메뉴 막대의 **캡처 → 캡처**를 선택하면 테두리 안쪽을 PNG로 저장합니다.
- `⌘R`을 누르면 현재 창의 내부를 24fps GIF로 녹화하며, 다시 누르거나 10초가 지나면 자동 저장합니다.
- `⌥⌘R`은 현재 창에서 원본 해상도 24fps의 최근 10초 상시 녹화를 켜고 끕니다. 빨간 테두리 상태에서 `⌘C`를 누르면 상시 녹화를 유지한 채 최근 10초를 GIF로 저장하며, `⌘R`로도 모드를 종료할 수 있습니다.
- GIF는 외부 라이브러리 없이 자체 전역 팔레트, 오차 확산 디더링, LZW 인코더로 생성합니다.
- **캡처 → 녹화 중 마우스 입력**을 켜고 녹화를 시작하면 중앙 영역의 클릭이 뒤쪽 앱으로 전달됩니다.
- **파일 → 저장 위치 변경…**에서 PNG와 GIF가 저장될 폴더를 선택할 수 있습니다. 기본값은 바탕화면입니다.
- **파일 → 저장 파일명…**에서 PNG, 일반 GIF, 상시 녹화 GIF에 똑같이 쓰이는 파일명 접두사를 바꿀 수 있습니다.
- **파일 → 파일 형식**에서 기존 PNG/GIF 또는 품질 90 WebP를 선택할 수 있습니다. WebP 선택 시 녹화 결과는 애니메이션 WebP로 저장됩니다.
- **PNClip → 오픈 소스 라이선스…**에서 내장된 libwebp의 라이선스와 특허 고지를 확인할 수 있습니다.
- 캡처와 녹화 결과는 자동으로 클립보드에도 복사됩니다. `⌘O`는 최근 결과를, `⌥⌘O`는 저장 폴더를 엽니다.
- 메뉴 막대의 PNClip 아이콘을 누른 뒤 화면에서 드래그하면 해당 영역 크기로 새 창이 만들어집니다. `Esc`로 취소할 수 있습니다.
- 저장 위치는 사용자의 바탕화면입니다.

## 실행

Xcode가 설치되어 있지 않아도 Command Line Tools가 있다면 다음으로 빌드할 수 있습니다.

```sh
make
open build/PNClip.app
```

`make`는 먼저 로컬 키체인에서 코드 서명이 가능한 `PNClip Development` 인증서를 찾습니다.
인증서가 있으면 해당 인증서와 `com.example.PNClip` 식별자로 앱 번들 전체를 서명하고,
다른 Mac처럼 인증서가 없으면 빌드가 실패하지 않도록 자동으로 ad-hoc 서명을 사용합니다.
ad-hoc 서명은 앱 실행에는 충분하지만 Mac마다 별도의 화면 기록 및 접근성 권한 승인이 필요합니다.
처음 캡처할 때 화면 기록 권한을 허용한 후 앱을 다시 실행하세요.

Xcode에서는 `PNClip.xcodeproj`를 열고 Run을 누르면 됩니다.

자체 GIF 인코더의 생성 및 ImageIO 재디코딩 테스트는 다음으로 실행할 수 있습니다.

```sh
make test-gif
```
