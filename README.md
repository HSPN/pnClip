# PNClip

AppKit과 Objective-C++로 만든 macOS 영역 캡처 앱입니다. 투명한 PNClip 창으로
영역을 직접 지정하거나 다른 앱의 창을 선택하여 PNG/GIF 또는 WebP로 캡처합니다.

## 조작법

### 캡처 영역 만들기

앱을 실행하면 파란 테두리의 자유 영역 창이 열립니다. 테두리 안쪽은 기본 80% 투명도로
뒤 화면을 보여 줍니다.

- 자유 영역 창의 안쪽이나 테두리를 드래그하면 창을 이동할 수 있습니다.
- 테두리와 네 모서리를 드래그하면 크기를 조절할 수 있습니다.
- 메뉴 막대 오른쪽의 PNClip 아이콘을 누르면 영역 선택 모드가 시작됩니다.
  - 드래그하면 드래그한 크기의 자유 영역 창이 만들어집니다.
  - 마우스 아래에서 감지된 창이나 UI 요소는 주황색 사각형으로 미리 표시됩니다. 클릭하면
    미리 표시된 사각형과 정확히 같은 영역의 연결 창이 만들어집니다.
  - 연결된 PNClip 창은 원본 창의 이동과 크기 변경을 따라가며 수동으로 크기를 바꿀 수 없습니다.
  - 연결된 창의 가운데는 마우스 입력이 원본 앱으로 통과합니다. 파란 테두리를 클릭하면 PNClip이 선택됩니다.
  - 영역 선택 중 우클릭하거나 아무 키나 누르면 취소됩니다.
- `⌘N` 또는 `⌘T`로 자유 영역 창을 추가할 수 있습니다.
- `⌘W` 또는 `Esc`로 현재 창을 닫고, `⌥⌘W`로 모든 PNClip 창을 닫습니다.
- 모든 창을 닫아도 메뉴 막대 아이콘은 유지되며, `⌘Q`로 앱을 완전히 종료합니다.

### 스크린샷

캡처할 PNClip 창을 선택하고 `⌘S`를 누르거나 **캡처 → 캡처**를 선택합니다.

- 자유 영역 창은 파란 테두리 안쪽의 화면을 캡처합니다.
- 다른 앱에 연결된 창은 그 원본 창만 캡처하므로 앞뒤에 겹친 다른 창은 포함하지 않습니다.
- 원본 창 전체를 선택하면 창 프레임과 그림자를 함께 캡처합니다. 창 내부의 UI 요소를 선택하면
  원본 창만 먼저 가져온 다음 표시했던 요소 영역을 잘라내므로 다른 위치가 섞이지 않습니다.
- 캡처 순간 테두리가 주황색으로 깜빡입니다.
- 결과는 저장 폴더에 기록되고 클립보드에도 자동으로 복사됩니다.

### 일반 녹화

`⌘R`을 누르면 선택한 PNClip 창에서 24fps 녹화를 시작합니다. 테두리가 주황색인 동안
`⌘R`을 다시 누르면 즉시 중지하고 저장하며, 선택한 녹화 길이에 도달해도 자동 저장됩니다.

**캡처 → 녹화 중 마우스 입력**을 미리 켜 두면 녹화 중 가운데 영역의 입력이 뒤쪽 앱으로
전달됩니다. 이 상태에서 다른 앱이 활성화되어도 전역 `⌘R`로 녹화를 중지할 수 있습니다.

### 최근 구간 상시 녹화

`⌥⌘R`을 누르면 최근 구간을 메모리에 유지하는 상시 녹화가 시작되고 테두리가 빨간색으로
바뀝니다.

- `⌘C`를 누를 때마다 현재 시점까지의 최근 5초 또는 10초를 저장합니다.
- 저장 후에도 상시 녹화는 계속됩니다.
- `⌘R` 또는 `⌥⌘R`을 다시 누르면 상시 녹화를 종료합니다.
- 설정한 길이를 초과한 오래된 프레임은 계속 버리므로 장시간 켜 둘 수 있습니다.

녹화 중에는 프레임 크기가 바뀌지 않도록 PNClip 창의 이동·크기 조절과 녹화 설정 변경이
잠깁니다. 메뉴 막대 오른쪽에는 현재 보유한 프레임을 기준으로 예상 결과 크기가 표시됩니다.

### 파일과 화질 설정

- **캡처 → 녹화 길이**에서 5초 또는 10초를 선택합니다. 기본값은 5초입니다.
- **캡처 → 녹화 해상도**에서 일반 또는 Retina를 선택합니다. Retina는 가로·세로 픽셀 수가
  각각 최대 2배가 되어 더 선명하지만 결과 파일과 웹 표시 크기가 커질 수 있습니다.
- **보기 → 중앙 투명도**는 현재 선택한 PNClip 창에만 적용됩니다. 새 창의 기본값은 80%이며
  창별 값은 따로 저장하지 않습니다.
- **파일 → 파일 형식**에서 `PNG / GIF` 또는 `WebP`를 선택합니다. PNG/GIF 모드는 스크린샷을
  PNG, 녹화를 무한 반복 GIF로 저장합니다. WebP 모드는 스크린샷과 녹화를 WebP로 저장합니다.
- **파일 → 저장 위치 변경…**에서 저장 폴더를 선택합니다. 기본 저장 위치는 바탕화면입니다.
- **파일 → 저장 파일명…**에서 모든 캡처 결과에 공통으로 붙는 파일명 접두사를 바꿉니다.
- `⌘O`는 가장 최근 결과를 열고 `⌥⌘O`는 현재 저장 폴더를 엽니다.

GIF는 외부 라이브러리 없이 자체 전역 팔레트, 오차 확산 디더링 및 LZW 인코더로 생성합니다.
WebP는 내장된 libwebp를 사용하며 **PNClip → 오픈 소스 라이선스…**에서 관련 고지를 확인할
수 있습니다.

### 단축키 요약

| 단축키 | 동작 |
| --- | --- |
| `⌘S` | 스크린샷 캡처 |
| `⌘R` | 일반 녹화 시작·중지 / 상시 녹화 종료 |
| `⌥⌘R` | 최근 구간 상시 녹화 시작·중지 |
| `⌘C` | 상시 녹화 중 최근 구간 저장 |
| `⌘N`, `⌘T` | 새 자유 영역 창 |
| `⌘W`, `Esc` | 현재 PNClip 창 닫기 |
| `⌥⌘W` | 모든 PNClip 창 닫기 |
| `⌘O` | 최근 캡처 결과 열기 |
| `⌥⌘O` | 저장 폴더 열기 |
| `⌘Q` | PNClip 완전히 종료 |

## 실행

Xcode가 설치되어 있지 않아도 Command Line Tools가 있다면 다음으로 빌드할 수 있습니다.

```sh
make
open build/PNClip.app
```

`make`는 먼저 로컬 키체인에서 코드 서명이 가능한 `PNClip Development` 인증서를 찾습니다.
인증서가 있으면 해당 인증서와 `com.example.PNClip` 식별자로 앱 번들 전체를 서명하고,
다른 Mac처럼 인증서가 없으면 빌드가 실패하지 않도록 자동으로 ad-hoc 서명을 사용합니다.
ad-hoc 서명은 앱 실행에는 충분하지만 Mac마다 별도의 화면 기록 및 접근성 권한 승인이 필요합니다.
처음 캡처할 때 화면 기록 권한을 허용한 후 앱을 다시 실행하세요.

Xcode에서는 `PNClip.xcodeproj`를 열고 Run을 누르면 됩니다.

자체 GIF 인코더의 생성 및 ImageIO 재디코딩 테스트는 다음으로 실행할 수 있습니다.

```sh
make test-gif
```
